Structure Of HTML

What is Structure of HTML?

The structure of an HTML document is a hierarchical tree of nested tags that tells a web browser how to organize and display a webpage's content.

Breakdown of Core Structural Elements

  1. !DOCTYPE html

    • Tells the browser that the document is written in modern HTML5.It must be on the very first line and does not require a closing tag

  2. html

    • The root element that wraps all other content on the page.The lang="en" attribute specifies the page language for search engines and screen readers.

  3. head

    • The invisible metadata container loaded by the browser.It holds structural configuration data, links to CSS styles, and SEO rules.

  4. meta charset="UTF-8"

    • Forces the webpage to decode text using the UTF-8 character set.This guarantees that emojis, special symbols, and foreign characters display properly

  5. meta name="viewport"

    • Configures the layout size for responsive web design.It ensures the webpage scales correctly on mobile devices and tablets.

  6. title

    • Sets the text displayed on the browser's tab for that page.
