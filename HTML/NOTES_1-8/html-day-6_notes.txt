HTML Forms - Complete Notes

What is a Form?
An HTML Form is used to collect user information and send it to a server.

Examples:

Login Form

Registration Form

Contact Form

Feedback Form

Job Application Form

Payment Form

Why Do We Use Forms?
Forms allow users to enter data such as:

Name

Email

Password

Phone Number

Address

Date of Birth

Resume Upload

Feedback

Basic Form Syntax
<form action="" method="">

</form>
Form Attributes
action
Specifies where the form data should be sent.

<form action="register.php">
method
Specifies how the data is sent.

<form method="get">
or

<form method="post">
GET
Data visible in URL

Used for search

POST
Data hidden

Used for Login, Registration, Payment

autocomplete
Turns browser suggestions ON or OFF.

<form autocomplete="on">
<form autocomplete="off">
enctype
Used while uploading files.

<form enctype="multipart/form-data">
novalidate
Disables HTML validation.

<form novalidate>

Interview Questions
What is a Form?
A Form is used to collect user data and send it to the server.

Difference Between GET and POST?
GET

Data visible in URL.

Less secure.

POST

Data hidden.

More secure.

What is Placeholder?
Displays hint text inside an input field.

Difference Between readonly and disabled?
readonly

Value visible.

Can be submitted.

Cannot edit.

disabled

Value visible.

Cannot edit.

Not submitted.

Difference Between Radio and Checkbox?
Radio

Single selection.

Checkbox

Multiple selections.

Difference Between Button and Submit?
Button

Performs custom actions.

Submit

Sends form data to the server.

Difference Between Select and Datalist?
Select

Fixed dropdown options.

Datalist

User can type or choose suggestions.

Difference Between Meter and Progress?
Meter

Displays a measured value.

Progress

Displays task completion progress.
