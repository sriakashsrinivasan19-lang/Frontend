Example:

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

</body>

Every line has a specific purpose. Let's understand each one in detail.

1. What is ?
Definition
<!DOCTYPE html> is called the Document Type Declaration.

It tells the browser that the document is written using HTML5.

Why Do We Need DOCTYPE?
Before HTML5, browsers used different rendering modes.

Without DOCTYPE:

Browser may enter Quirks Mode

Old browser behavior is used

CSS may not work correctly

Layout may break

With DOCTYPE:

Browser enters Standards Mode

HTML5 and CSS behave correctly

Same output across modern browsers

Syntax
<!DOCTYPE html>
Why is it not a Tag?
DOCTYPE is not an HTML tag.

It is a declaration that is read before the HTML document begins.

History of DOCTYPE
HTML 4.01
DOCTYPE was very long.

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN">
HTML5
Simplified to:

<!DOCTYPE html>

Why "8" in UTF-8?
The number 8 refers to an 8-bit unit (1 byte).

UTF-8 stores characters using 1 to 4 bytes.

English letters usually use 1 byte (8 bits).

Other languages and emojis may use 2, 3, or 4 bytes.

What is a Bit?
A Bit is the smallest unit of data.

What is 64-bit?
64-bit refers to the processor or operating system architecture.

64 Bits = 8 Bytes
A 64-bit CPU can process more data at once and access much more memory than a 32-bit CPU.

This is different from UTF-8. The "8" in UTF-8 refers to bytes used for encoding text, while "64-bit" refers to CPU architecture.

What is lang?

Meta tags provide information about the webpage for browsers, search engines, and social media platforms.
